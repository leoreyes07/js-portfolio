⚙️ Getting Started

Follow these steps to run the project locally:

1. Clone the repository
git clone https://github.com/leoreyes07/js-portfolio.git
2. Navigate to the project folder
cd js-portfolio
3. Install dependencies
npm install
4. Run the development server
npm start

The app will run on:

http://localhost:3000
✏️ Customization

To personalize your portfolio:

Update your personal information in the main configuration file (e.g. App.js or a config object)
Replace images inside /src/images
Add your own projects and links
Modify styles in CSS files
